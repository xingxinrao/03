# AI 简历优化助手作品集说明

本文件夹是一个面向 **AI 产品实习** 的完整作品集，核心项目是「AI 简历优化助手」。

## 文件结构

- `00_作品集封面与目录.md`：作品集封面、个人信息和目录
- `01_AI简历优化助手_PRD.md`：产品需求说明
- `02_AI简历优化助手_竞品分析.md`：竞品分析
- `03_AI简历优化助手_用户流程与原型说明.md`：用户流程与原型说明
- `04_AI产品实习_项目面试话术.md`：面试讲解话术
- `05_三天完成作品执行清单.md`：执行清单
- `06_作品亮点总结.md`：项目亮点总结
- `07_作品集使用说明.md`：打开、截图与展示方式
- `index.html`：部署后的默认入口页
- `AI简历优化助手_网页原型.html`：可直接打开的网页原型

## 如何查看

直接双击 `AI简历优化助手_网页原型.html` 即可查看页面。

如果你想让页面通过本地 mock 接口工作，可以先启动本地服务再访问：

```bash
npm install
npm start
```

然后打开：

`http://localhost:3000/AI简历优化助手_网页原型.html`

## 建议展示方式

1. 先展示 `00_作品集封面与目录.md`
2. 再展示 `01` 到 `06` 的文档材料
3. 最后展示 `AI简历优化助手_网页原型.html` 的截图

这样会更像一个完整成品作品集，而不是零散文档。
